# AI Patient Kiosk

The application lives in [`patient-checkin-system/`](patient-checkin-system/). See its [README](patient-checkin-system/README.md) for details and troubleshooting.

## Run it (one command)

You need **Node.js 18+** and **Python 3.9 – 3.12** installed.

- **Windows:** double-click `start.bat` (or run it from a terminal).
- **macOS / Linux:** run `./start.sh`.

The first run installs everything (a few minutes, since TensorFlow is large). After that it starts right away.
When it's ready, the app opens at http://localhost:3000.

Staff login (red lock button, bottom-right): `admin` / `password123`.
